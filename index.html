Questions

Good to know

How do I install Lumen?

Download Lumen.exe, run it, and it adds a Lumen profile to your official Minecraft launcher. Pick that profile and hit play.

Is it free?

Yes — Lumen is completely free. No subscription, no paywalled features, no account required.

Which versions are supported?

Everything from 1.8 through 1.21, so your favorite PvP version and the latest release are both covered.

Will it work with my mods?

Lumen plays nicely with Fabric mods and resource packs, so you can keep the setup you already use.

Does it change my Minecraft install?

No. Lumen runs as its own launcher profile and leaves your vanilla install untouched — remove it any time.
